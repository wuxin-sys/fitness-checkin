## 2. 环境准备

### 2.1 安装 JDK 1.8+

```bash
# 下载地址：https://www.oracle.com/java/technologies/downloads/
# 安装后验证
```


```bash
# 下载地址：https://dev.mysql.com/downloads/mysql/5.7.html
```

```bash
# 下载地址：https://nodejs.org/（选择 LTS 版本）

node -v    # 应 >= 16
```

## 4. 后端配置与启动

### 4.1 配置文件

编辑 `fitness-server/src/main/resources/application.yml`：

```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/fitness_checkin?useUnicode=true&characterEncoding=utf-8&useSSL=false&serverTimezone=Asia/Shanghai
    username: root          # ← 改为你的 MySQL 用户名
    password: root          # ← 改为你的 MySQL 密码
```

### 4.2 Maven 打包

```bash
cd fitness-server

# 清理并打包（跳过测试）
mvn clean package -DskipTests

# 打包成功后，target 目录下生成 fitness-server-1.0.0.jar
```

### 4.3 启动后端

**方式一：Maven 直接运行（开发）**

```bash
cd fitness-server
mvn spring-boot:run
```

**方式二：JAR 包运行（生产）**

```bash
java -jar fitness-server/target/fitness-server-1.0.0.jar
```

### 4.4 验证

启动成功后会看到：

```
========================================
  健身打卡系统后端服务启动成功！
  访问地址: http://localhost:8080
========================================
```

浏览器访问 `http://localhost:8080/api/user/login`（POST），使用 Postman 测试登录接口确认后端正常。

## 5. 前端配置与启动

### 5.1 安装依赖

```bash
cd fitness-web
npm install
```

### 5.2 开发模式启动

```bash
npm run dev
```

启动后终端显示：

```
VITE v5.x.x  ready in xxx ms
➜  Local:   http://localhost:5173/
```

### 5.3 访问系统

| 页面 | 地址 |
|------|------|
| 用户登录 | http://localhost:5173/login |
| 用户注册 | http://localhost:5173/register |
| 用户首页 | http://localhost:5173/home |
| 管理员登录 | http://localhost:5173/admin/login |

### 5.4 生产构建

```bash
npm run build

# 构建产物在 dist/ 目录
# 可将 dist/ 部署到 Nginx 等 Web 服务器
```

**Nginx 配置示例：**

```nginx
server {
    listen       80;
    server_name  localhost;

    # 前端静态文件
    location / {
        root   /path/to/fitness-web/dist;
        index  index.html;
        try_files $uri $uri/ /index.html;
    }

    # 后端 API 代理
    location /api/ {
        proxy_pass http://localhost:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

## 8. 常见问题

### Q1: Maven 打包报错 "Could not resolve dependencies"

**解决：** 检查网络连接，确保能访问 Maven 中央仓库。如在国内可配置阿里云镜像：

```xml
<!-- ~/.m2/settings.xml -->
<mirrors>
  <mirror>
    <id>aliyun</id>
    <mirrorOf>central</mirrorOf>
    <name>Aliyun Maven</name>
    <url>https://maven.aliyun.com/repository/public</url>
  </mirror>
</mirrors>
```

### Q2: 启动后端报 "Access denied for user"

**解决：** 检查 `application.yml` 中 `spring.datasource.username` 和 `password` 是否正确。

### Q3: 启动后端报 "Unknown database 'fitness_checkin'"

**解决：** 未执行初始化 SQL，先执行 `docs/init.sql`。

### Q4: 前端页面空白

**解决：** 
1. 确认 `npm install` 已完成
2. 打开浏览器开发者工具（F12），查看 Console 是否有报错
3. 确认后端已启动

### Q5: 登录后接口报 401

**解决：** Token 过期或未正确携带。清除浏览器 localStorage 后重新登录。

### Q6: 端口被占用

**解决：**
- 后端端口 8080：修改 `application.yml` 中 `server.port`
- 前端端口 5173：修改 `vite.config.js` 中 `server.port`，同时修改 proxy target

## 9. 快速启动脚本

将以下内容保存为 `start.bat`（Windows）放在项目根目录：

```batch
@echo off
echo ========================================
echo   健身打卡系统 - 一键启动
echo ========================================

echo [1/3] 启动后端服务...
start "Fitness-Server" cmd /c "cd fitness-server && mvn spring-boot:run"

echo [2/3] 等待后端启动（15秒）...
timeout /t 15 /nobreak > nul

echo [3/3] 启动前端服务...
start "Fitness-Web" cmd /c "cd fitness-web && npm run dev"

echo ========================================
echo   启动完成！
echo   用户端: http://localhost:5173
echo   管理端: http://localhost:5173/admin/login
echo ========================================
pause
```
